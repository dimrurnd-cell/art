# Онлайн-каталог «Арт-Ростов» — установка на Tilda (HEAD + блок T123)

Каталог состоит из двух режимов просмотра, между которыми переключаются кнопками
в шапке виджета:

- **Виртуальный зал** — 3D-тур: посетитель идёт по галерее, полотна висят на стенах,
  под каждым табличка с фото художника и названием работы. Нажатие на полотно
  открывает полную карточку художника с кнопкой «Хочу купить картину».
  Управление: перетаскивание/свайп, колесо мыши, клавиши W/S и стрелки,
  кнопки шага и переход сразу к нужному художнику.
- **Каталог** — прежняя карусель карточек художников.

Адаптация для сайта на Tilda. Отличия от Django-версии:

| | Django-версия | Tilda-версия |
|---|---|---|
| Статика (JS/CSS/фото/шрифт) | `/static/` сайта | CDN jsDelivr прямо из этого GitHub-репозитория |
| Код вставки | один Snippet | HEAD-блок (стили) + блок T123 (разметка и скрипт) |
| Форма «Хочу купить» | своя модалка + эндпоинт `artcatalog` | нативная попап-форма Tilda (`data-tilda-popup`) |
| Письмо на ads@donexpocentre.ru | Django `send_mail` | приёмщик данных Tilda (Email) |
| Защита от спама | honeypot + rate limit | встроенная в формы Tilda |

Карусель, страницы художников, лайтбокс, дизайн — без изменений.

> Код вставки закреплён за конкретным коммитом репозитория
> (`…/gh/dimrurnd-cell/art@<хеш>/…`), поэтому работает сразу — мержить ветку в `main`
> не обязательно. Проверка: подставьте `artists.json` к адресу из `data-base`
> (файл `tilda-t123.html`) и откройте его
> в браузере — должен показаться JSON со списком художников.

## Шаг 1. Попап-форма для заявок

1. В Tilda добавьте на страницу блок **BF502N** («Форма: всплывающее окно», категория «Форма»).
2. В настройках блока:
   - **Ссылка для открытия окна**: `artbuy` (итоговый хук — `#popup:artbuy`);
   - поля формы:
     - «Телефон» — тип *Телефон*, имя переменной `phone`, обязательное;
     - «Email» — тип *Email*, имя переменной `email`, обязательное;
     - **скрытое поле** (тип *Hidden*), имя переменной `artist` — сюда виджет подставит имя художника;
     - **скрытое поле** (тип *Hidden*), имя переменной `work` — название выбранной работы;
     - **скрытое поле** (тип *Hidden*), имя переменной `workurl` — прямая ссылка на
       изображение работы. Поле необязательное, но с ним менеджер сразу видит,
       о какой именно картине речь, даже если название пустое или у художника
       несколько похожих вещей;
   - включите чекбокс согласия на обработку персональных данных (Настройки формы → «Соглашение с условиями») и укажите ссылку на политику;
   - заголовок окна: «Хочу купить», текст кнопки: «Отправить заявку».
3. В **приёмщиках данных** формы подключите **Email** и укажите `ads@donexpocentre.ru`
   (Сайт → Настройки сайта → Формы → Email, затем отметьте приёмщик в настройках формы).
   Заявки также будут копиться в CRM Tilda («Заявки»).
4. Оформите попап в фирменных цветах: фон `#EFE3C3`, кнопка `#E4736F`, текст `#211D17`.

Тема письма у Tilda формируется автоматически; художник, работа и ссылка на неё
придут в письме отдельными полями `artist`, `work` и `workurl`.

**Какую именно картину хочет человек.** Виджет заполняет скрытые поля перед
тем, как открыть форму:

| Откуда нажали «Хочу купить картину» | `artist` | `work` | `workurl` |
|---|---|---|---|
| из открытой работы (в зале или в карточке) | имя художника | название работы | ссылка на изображение |
| из карточки художника целиком | имя художника | `не выбрана (заявка из карточки художника)` | пусто |

То есть работа известна всегда, когда посетитель нажал кнопку, глядя на
конкретную картину. Если он нажал её в карточке художника, конкретная работа
не выбрана — это видно по полю `work`, и менеджер уточняет при звонке.

## Шаг 2. Вставка каталога — два блока

Код разделён на две части: стили идут в `<head>`, разметка и скрипт — в блок T123.
Так каталог не мелькает неоформленным при загрузке страницы.

**Блок 1 — в HEAD** (файл `tilda-head.html`):
Настройки страницы → «Дополнительно» → «HTML-код для вставки внутрь HEAD».
Если каталог нужен на нескольких страницах — Настройки сайта → «Ещё» → «HTML-код в HEAD».

**Блок 2 — в T123** (файл `tilda-t123.html`):
добавьте блок **T123** («Другое → HTML-код») в то место страницы, где должен
появиться каталог, и вставьте содержимое файла без изменений.

Затем опубликуйте страницу.

Атрибут `data-tilda-popup="popup:artbuy"` должен совпадать с именем попапа из шага 1.
Если назвали попап иначе — поменяйте значение в коде.

> **Если доступа к HEAD нет** — вставьте в T123 файл `tilda-embed.html`: в нём то же
> самое одним куском, вместе со стилями. Работает так же, только при первой загрузке
> каталог на долю секунды виден неоформленным.
>
> Скрипт в любом случае проверяет, подключены ли стили, и подключает их сам, если их
> нет, — поэтому забытый HEAD-блок каталог не сломает.

## Как это работает

- Виджет грузит `artists.json`, изображения и шрифт с
  `https://cdn.jsdelivr.net/gh/dimrurnd-cell/art@main/catalog/static/artcatalog/…` —
  jsDelivr бесплатно раздаёт файлы публичных GitHub-репозиториев.
- Кнопка «Хочу купить» подставляет имя художника и работу в скрытые поля
  `artist`/`work` всех форм на странице и открывает попап `#popup:artbuy`.
  Дальше всё делает Tilda: валидация, отправка, письмо, сообщение об успехе.

## Обновление контента

Данные художников редактируются в этом репозитории
(`catalog/static/artcatalog/artists.json` + изображения, как описано в `../README.md`).

Код вставки закреплён за хешем коммита — такой URL jsDelivr кеширует навсегда,
поэтому после правок нужно один раз обновить код в T123:

1. Закоммитьте изменения и узнайте новый хеш (`git log -1 --format=%H` или на GitHub).
2. Замените старый хеш на новый в обоих блоках — и в HEAD, и в T123.
3. Переопубликуйте страницу.

Альтернатива — заменить хеш на `@main` (после мержа ветки): тогда правки будут
подхватываться без изменения кода, но с задержкой до 12 часов (кеш jsDelivr;
сбрасывается вручную через `https://purge.jsdelivr.net/gh/dimrurnd-cell/art@main/...`).

## Известное ограничение jsDelivr

CDN отдаёт файлы с ближайшего к посетителю узла, и состояние кеша на разных
узлах различается. На практике это проявляется так: при включённом VPN
(запрос уходит на другой узел) те же адреса могут вернуть **404**, хотя без
VPN всё открывается. Причина — узел, который ещё не забрал файлы из GitHub,
а сам коммит лежит в неосновной ветке репозитория.

Что с этим делать:

- **надёжнее всего** — раздавать файлы со своего сервера, см. `../server/`;
- если остаётесь на CDN, сошлитесь на ветку `main` (после мержа) или на тег
  релиза вместо хеша коммита в рабочей ветке — такие адреса jsDelivr
  обслуживает стабильнее;
- либо переключитесь на GitHub Pages (ниже).

## Если jsDelivr недоступен

У части российских провайдеров cdn.jsdelivr.net периодически блокируется.
Если каталог не загружается — переключитесь на GitHub Pages:

1. На GitHub: Settings → Pages → Source: «Deploy from a branch», выберите ветку
   `main` (или рабочую) и папку `/ (root)`, сохраните.
2. Через пару минут статика станет доступна по адресу
   `https://dimrurnd-cell.github.io/art/catalog/static/artcatalog/…`.
3. Замените jsDelivr-префикс на этот в обоих блоках (HEAD и T123).

GitHub Pages отдаёт правки через несколько минут после пуша — пункт про кеш
выше при этом не нужен.

## Проверка после установки

1. Открывается виртуальный зал: по нему можно пройти (свайп/колесо/W/S/кнопки),
   полотна и таблички под ними видны, переключатель «Каталог» показывает карусель.
2. Нажатие на полотно открывает карточку художника; работы открываются в лайтбоксе.
3. «Хочу купить картину» открывает попап Tilda; отправьте тестовую заявку — письмо приходит
   на ads@donexpocentre.ru, в нём заполнены поля `artist` (и `work`, если жали из лайтбокса).
4. Заявка видна в Tilda CRM («Заявки»).
5. Мобильная версия: зал управляется свайпом, карусель по одной карточке,
   горизонтального скролла страницы нет.

## Запасной вариант без попапа Tilda

Если удобнее собственная форма виджета (как в Django-версии), уберите
`data-tilda-popup` и задайте `data-endpoint` — URL любого сервиса приёма форм,
принимающего JSON POST (поля `phone`, `email`, `artist`, `work`, `page`).
Без бэкенда рекомендуем всё же попап Tilda — это штатный и бесплатный путь.
