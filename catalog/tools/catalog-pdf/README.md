# Карта печатного каталога

Здесь лежит результат разбора печатного каталога «Арт-Ростов» (PDF, 200
страниц, 1,4 ГБ — сам файл в репозиторий не кладём, он приложен к релизу
`catalog-pdf`).

## Зачем

В папке участника фотографии лежат вперемешку, и по имени файла не всегда
понятно, где портрет автора, а где снимок работы. В печатном каталоге это
известно точно: портрет стоит в левой колонке, левее всех прочих
изображений. Карта переносит это знание на исходные файлы.

## Файлы

| Файл | Что внутри |
|---|---|
| `catalog-map.json` | 175 записей: заголовок, раздел, портрет и работы с отпечатками |
| `pdf-titles.json` | заголовки всех 200 страниц (в PDF текст переведён в кривые, поэтому прочитаны с изображения) |

## Как устроена запись

```json
{
  "page": 8,
  "title": "Авдеев Михаил Анатольевич",
  "section": "Арт-салон",
  "portrait": { "x": 34.7, "px": [698, 572], "hash": "6359e141e1e061e3", "sd": 74.8 },
  "works":    [ { "x": 215.4, "hash": "385894ac56332632", "sd": 45.5 } ],
  "sure": true
}
```

`hash` — отпечаток dHash (9×8, 64 бита). По нему тот же снимок находится
среди исходных файлов участника: сравнивается расстояние Хэмминга, свой
файл отстоит на 2–9 бит, чужой — на 20 и больше.

`sure: false` означает, что самое левое изображение оказалось заметно
правее обычного (x > 80). У 171 записи из 175 портрет стоит на x ≤ 80;
выбросов четыре, и это страницы, где портрета нет вовсе — участник его не
прислал, и портретом ошибочно назначена работа. Эти записи нужно проверить
руками.

## Что важно знать про каталог

Разделов три, а не два:

| Страницы | Раздел | Записей |
|---|---|---|
| 8–131 | Арт-салон | 115 |
| 134–175 | ДПИ / ярмарка | 40 |
| 178–200 | Галереи | 20 |

Раздел ДПИ в анкетах Word отсутствует полностью.

Часть участников занимает две страницы: на второй только продолжение работ,
без заголовка и портрета. Такие страницы приклеены к предыдущей записи
(поле `pages` перечисляет исходные номера) — иначе часть работ терялась бы.

## Как пересобрать

```bash
pip install pymupdf Pillow
python3 ../pdf-portraits.py catalog.pdf \
    --titles pdf-titles.json --merge-untitled --json catalog-map.json
```
